# 제본 치수 계산기 v0.3

존재공작소용 제본 치수 계산기입니다.

## 실행

가장 단순한 방법:
- `index.html`을 브라우저에서 열기

로컬 서버 사용:
- VS Code Live Server
- 또는 Python: `python -m http.server 8000`

브라우저에서 `http://localhost:8000` 접속.

## 테스트

Node.js가 있으면:

```bash
node test.mjs
```

## 현재 규칙

### 공통
- 힌지: 사용자 입력, 기본값 7.8mm

### 패브릭 평등
- 커버 가로 = 속지 가로 + 1.0mm (잠정)
- 커버 세로 = 속지 세로 + (상·하 돌출량 × 2), 기본 돌출량 3.5mm
- 책등 폭 = 속지 두께 + 8.5mm, 0.5mm 단위 올림 (잠정)
- 책등 세로 = 커버 세로

### 라운드
- 커버 가로 = 속지 가로 - 곡률 보정
  - 얕음: -1mm
  - 일반: -2mm
  - 깊음: -3mm
- 커버 세로 = 속지 세로 + (상·하 돌출량 × 2), 기본 돌출량 5.0mm
- 책등 폭 = 속지 두께 + 19mm, 0.5mm 단위 올림 (강한 후보 규칙)
- 책등 세로 = 커버 세로

## 설계 원칙

- 계산식은 `rules.js`에만 둔다.
- UI는 계산 규칙을 직접 갖지 않는다.
- 책등 폭은 계산값보다 작게 재단하지 않는다.
- 새 실측값이 쌓이면 `rules.js`의 상수만 수정한다.

## v0.3 입력 동작
- 제본 유형을 바꾸면 돌출량은 해당 유형의 기본값으로 변경됩니다.
- 힌지 간격은 유형을 바꿔도 입력값을 유지합니다.
- 돌출량은 0 이상, 힌지 간격은 0보다 큰 숫자여야 합니다.
- 보드 두께 입력은 제거했습니다. 입력 저장 기능은 없습니다.

## 주요 파일
- index.html: 입력과 결과 화면
- styles.css: 화면 스타일
- app.js: 입력 이벤트와 결과 표시
- rules.js: 기본값, 계산식, 입력 검증
- test.mjs: 기존 및 v0.3 계산 테스트
- CODEX_TASK.md: 유지보수 원칙


## v0.3 겉재료 1차 재단
- 겉재료 기본 외곽 재단 여유: 패브릭 20mm, 인조가죽 30mm, 천연가죽 20mm. 재료 변경 시 기본값을 제안하며 직접 수정할 수 있습니다.
- 외곽 재단 여유는 보드 바깥쪽 가장자리부터 겉재료 끝까지의 거리이며, 두께를 돌아가는 부분과 안쪽 접힘을 포함합니다. 0 이상의 숫자를 입력합니다.
- 케이스 전개 가로 = 커버 보드 가로 × 2 + 책등 보드 가로 + 힌지 간격 × 2.
- 겉재료 재단 가로 = 케이스 전개 가로 + 외곽 재단 여유 × 2.
- 겉재료 재단 세로 = 커버 보드 세로 + 외곽 재단 여유 × 2.
- 내부 소수값을 유지하고 최종 겉재료 재단 치수 표시만 1mm 단위로 올립니다. 기본값과 계산은 rules.js에서 관리합니다.
- 보드 재단·조립·겉재료 1차 재단으로 결과를 구분합니다. 접착 후 최종 가장자리 정리는 실제 상태를 보고 수행합니다.

## 평상시 사용 방법
- 프로젝트 폴더의 `제본계산기_실행.bat`을 더블클릭하면 기본 브라우저에서 계산기가 열립니다. ChatGPT나 Codex 앱을 열 필요가 없습니다.
- 바탕화면에서 사용하려면 BAT 파일의 바로 가기를 바탕화면에 만들어 사용하세요. BAT 파일만 다른 폴더로 옮기지는 마세요.
- Python이 있으면 Python 서버를 사용하고, 없으면 Windows 기본 PowerShell 서버를 사용합니다. 별도 설치는 필요하지 않습니다.
- 기본 주소는 `http://127.0.0.1:8001/`입니다. 같은 계산기가 실행 중이면 기존 서버를 사용하며, 다른 프로그램이 포트를 사용하면 8002 또는 8003을 사용합니다.
- 서버 창은 숨겨 실행됩니다. 브라우저를 닫아도 서버는 유지되어 다음 실행 때 다시 사용합니다. Windows를 재시작하면 종료됩니다.
- `제본계산기_실행.ps1`은 BAT에서 호출하는 서버 실행 도구이므로 같은 폴더에 보관하세요.
