# 제본 치수 계산기 v0.5

존재공작소 제작 실측에 기반한 커버 보드·책등 보드·힌지·겉재료 1차 재단 계산기.

## 적용 규칙 (2026-10-10)

| 유형 | 커버 폭 | 책등 보드 폭 | 상·하 돌출(각각) | 비고 |
|---|---|---|---|---|
| 패브릭 평등 | 속지 폭과 동일 | 속지 두께 + 5mm | 3mm | 평등 |
| 패브릭 라운드 | 속지 폭 − 6mm | 속지 두께 + 10mm | 3mm | 얕은 곡률 |
| 가죽 라운드(천연·인조) | 속지 폭 − 6mm | 속지 두께 + 10mm | 3mm | 얕은 곡률 |

- 보드 세로 = 속지 세로 + 상·하 돌출량 × 2. 커버·책등 보드에 공통 적용.
- 책등 보드 폭은 0.5mm 단위 올림. 힌지 기본값 7.8mm.
- 라운드의 '얕은 곡률'은 제작 방식이며 별도 곡률 반경 계산이 아님. 기존 '얕음 −1mm/일반 −2mm/깊음 −3mm' 커버 폭 보정은 삭제함.
- 재료: 패브릭 턴인 20mm, 인조가죽 30mm, 천연가죽 20mm. 엣지 회전 여유 공통 기본값 2.7mm.
- 모든 치수는 잠정 제작 기준. 실측 후 개선.

## 직접 수정 가능한 최종 보드 재단

- 커버 보드의 가로/세로와 책등 보드의 가로/세로를 각각 수정할 수 있음. 자동 권장 치수는 별도로 표시됨.
- 수정한 최종 치수가 케이스 전개 가로와 겉재료 1차 재단 계산에 즉시 반영됨.
- 속지 가로·세로·두께, 상·하 돌출량, 제본 유형 변경 시 보드 입력을 새 자동 권장값으로 초기화함. `권장 치수 복원` 버튼으로도 복원 가능.
- 겉재료 선택 변경 시 호환되는 제본 유형으로 자동 전환하고 관련 기본 치수를 다시 계산함.
- 별도 저장 기능은 제공하지 않음.

## 겉재료 계산

- 한쪽 총 재단 여유 = 안쪽 턴인 목표 + 엣지 회전 여유.
- 케이스 전개 가로 = (최종 커버 보드 폭 × 2) + 최종 책등 보드 폭 + (힌지 간격 × 2).
- 겉재료 가로 = 케이스 전개 가로 + (한쪽 총 재단 여유 × 2).
- 겉재료 세로 = 최종 커버/책등 보드 중 큰 세로 + (한쪽 총 재단 여유 × 2).
- 내부 소수값은 유지하고 최종 겉재료 표시 치수만 1mm 단위 올림.

## 개발 및 검증

- `rules.js`: 모든 치수 규칙과 계산 함수.
- `app.js`: 사용자 입력·자동 권장·재단 치수 수정과 표시.
- `index.html`, `styles.css`: UI.
- `test.mjs`: 세 유형/천연·인조가죽, 수동 편집, 겉재료 계산 및 오류 테스트.
- 테스트: `node test.mjs`
