# 제본 치수 계산기 v0.9

존재공작소 제작 실측에 기반한 커버 보드·책등 보드·힌지·겉재료 1차 재단 계산기.

## 적용 규칙 (2026-10-10, 가죽 라운드 2026-10-18 수정)

| 유형 | 커버 폭 | 책등 보드 폭 | 상·하 돌출(각각) | 비고 |
|---|---|---|---|---|
| 패브릭 평등 | 속지 폭과 동일 | 속지 두께 + 5mm | 3mm | 평등 |
| 패브릭 라운드 | 속지 폭 − 6mm | 속지 두께 + 10mm | 3mm | 얕은 곡률 |
| 가죽 라운드(천연·인조) | 속지 폭 − 4mm | 속지 두께 + 8mm | 3mm | 얕은 곡률 |

- 보드 세로 = 속지 세로 + 상·하 돌출량 × 2. 커버·책등 보드에 공통 적용.
- 책등 보드 폭은 0.5mm 단위 올림. 힌지 기본값 7.8mm.
- 라운드의 '얕은 곡률'은 제작 방식이며 별도 곡률 반경 계산이 아님. 기존 '얕음 −1mm/일반 −2mm/깊음 −3mm' 커버 폭 보정은 삭제함.
- 재료: 패브릭 턴인 20mm, 인조가죽 30mm, 천연가죽 20mm. 엣지 회전 여유 공통 기본값 2.7mm.
- 모든 치수는 잠정 제작 기준. 실측 후 개선.

2026-10-18 실측 조정: 가죽 라운드만 커버 폭 +2mm, 책등 보드 폭 −2mm를 권장값에 반영. 예: 속지 133×193×23mm → 커버 보드 129×199mm, 책등 보드 31×199mm. 패브릭 두 유형은 변경하지 않음.

## 직접 수정 가능한 최종 보드 재단

- 커버 보드의 가로/세로와 책등 보드의 가로/세로를 각각 수정할 수 있음. 자동 권장 치수는 별도로 표시됨.
- 수정한 최종 치수가 케이스 전개 가로와 겉재료 1차 재단 계산에 즉시 반영됨.
- 속지 가로·세로·두께, 상·하 돌출량, 제본 유형 변경 시 보드 입력을 새 자동 권장값으로 초기화함. `권장 치수 복원` 버튼으로도 복원 가능.
- 겉재료 선택 변경 시 호환되는 제본 유형으로 자동 전환하고 관련 기본 치수를 다시 계산함.
- 별도 저장 기능은 제공하지 않음.

## 가죽·북클로스 표지 분할 치수 (2026-10-18)

- 보드 재단 아래 ‘분할 적용’ 체크박스(기본 켬)를 추가. 분할비율은 기본 20%이며 편집할 수 있음.
- ‘앞·뒤 표지 각각의 분할폭’ = 최종 커버보드 가로 × (분할비율 ÷ 100). **책등을 제외한 표지 보드 가로**가 기준.
- ‘책등·힌지 포함 전체 표면 전개폭’ = 양쪽 분할폭 합계 + 최종 책등보드 가로 + 힌지 간격 × 2.
- 예: 가죽 라운드, 속지 133×193×23mm, 보드 129×199 / 책등 31×199, 힌지 7.8, 분할 20% → 각 표지 25.8mm, 전체 98.2mm.
- 직접 수정한 보드 가로와 힌지 간격, 분할비율을 즉시 반영. 가죽 또는 패브릭(북클로스) 유형 모두 계산 가능.
- 결과는 맞댐 경계 위치를 위한 표면 전개폭. 곡률/소재 두께 보정, 좌우 트리밍 여유, 접힘을 포함한 초벌 재단 폭이 아니므로 구분하여 사용.

## 겉재료 계산

- 한쪽 총 재단 여유 = 안쪽 턴인 목표 + 엣지 회전 여유.
- 케이스 전개 가로 = (최종 커버 보드 폭 × 2) + 최종 책등 보드 폭 + (힌지 간격 × 2).
- 겉재료 가로 = 케이스 전개 가로 + (한쪽 총 재단 여유 × 2).
- 겉재료 세로 = 최종 커버/책등 보드 중 큰 세로 + (한쪽 총 재단 여유 × 2).
- 내부 소수값은 유지하고 최종 겉재료 표시 치수만 1mm 단위 올림.

## 돌출띠 중심선 및 속지 3규격 (2026-11-12, v0.7)

- 속지 프리셋: 소형 B5 반접 128.5×182mm, 중형 A4 반접 148.5×210mm, 대형 B4 반접 182×257mm. 프리셋 선택 시 가로·세로만 채우고 기존 두께는 유지. 수동 변경 시 사용자 입력 모드로 복귀.
- 최종 책등 보드 높이 H를 기준으로 상단에서 중심선까지 계산. 보드 최종 세로 수동 변경에 반응.
- 5개 표준: 구획 3:4:4:4:4:3 (22단위), 위치 H×(3,7,11,15,19)/22.
- 6개 대형 비교안: 구획 3:4:4:4:4:4:3 (26단위), 위치 H×(3,7,11,15,19,23)/26. 대형 표준 확정은 보류.
- 이 비율은 존재공작소의 제작 제안이며 역사적 유일 규격이 아님. 돌출띠 자체 두께는 중심선 위치와 별개.
- 기존 보드·힌지·겉재료 공식은 변경 없음. `node test.mjs` 회귀 테스트에 3규격 및 5/6개 대칭 검증 추가.


## 2026-11-12 v0.8: 분할 패브릭 2장 재단값

- 힌지 간격은 상단에서 숫자로 직접 입력하며 7.8mm가 기본값. 원하는 양수로 자유롭게 수정할 수 있고 기존 보드 공식은 유지.
- 힌지 간격 변경은 분할 가죽 표면 전개폭과 일체형 겉재료 폭에 반영. 패브릭 두 장은 각 커버 바깥쪽에만 놓이므로 패브릭 재단 폭에는 힌지 간격이 직접 영향을 주지 않음.
- 분할 북클로스·패브릭의 한 장당 재단 가로 = 최종 커버보드 가로 × (1 − 분할비율) + 패브릭 턴인 20mm + 엣지 회전 여유.
- 분할 북클로스·패브릭의 한 장당 재단 세로 = 최종 커버보드 세로 + 2×(패브릭 턴인 20mm + 엣지 회전 여유).
- 외곽 3변만 턴인: 가운데 분할 경계는 맞댐, 겹침 없음. 결과는 1mm 단위 올림이며 앞·뒤 각각 1장씩 총 2장.
- 분할비율 100%이면 패브릭 0장. 맞댐선의 가공·트리밍 오차나 소재 두께에 따른 최종 보정은 별도.
- 예: 가죽 라운드, 속지 133×193×23mm, 보드 129×199mm, 분할 20% → 북클로스 126×245mm(2장).
- 아래 일체형 겉재료 재단값은 분할 재단에 적용하지 않도록 레이블 분리. 기존 계산식 유지.

## 황금비 슬림형 속지 추가 (2026-11-13, v0.9)

- 일반형 B5 반접 128.5×182mm·A4 반접 148.5×210mm·B4 반접 182×257mm는 그대로 유지.
- 황금비 슬림형 소형 112.5×182mm(B5 반접 기반), 중형 129.8×210mm(A4 반접 기반)를 속지 규격 드롭다운에 추가.
- 계산: 세로 ÷ φ(φ = (1+√5)/2 ≈ 1.618)를 소수 첫째 자리까지 반올림하여 속지 폭 산출; 세로는 유지. 일반형과 비교해 앞배 폭 재단량은 각각 16.0mm·18.7mm.
- 과거 황금비 실험 120.5×195mm·124~125×190mm 등은 현행 규격 프리셋에 섞지 않음.
- 슬림형 선택 시 기존 보드, 분할, 겉재료 및 돌출띠 계산을 동일 엔진으로 수행. 판형 비례는 설계 출발점이며 실제 제작 품질을 보증하지 않음.
- 소·중 슬림만 추가; 대형은 기존 일반형을 유지. 기존 보드/힌지 공식 변경 없음.
